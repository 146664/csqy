> [!TIP]
> **🟢 游戏萌新科普：MOD 与地图怎么安装？**
> 
> 下载资源并解压后，请找到您的游戏安装根目录（即包含 `hl2.exe` 的文件夹）：
> 
> 1. **前提条件：** 进入游戏 -> 选项 -> 键盘 -> 高级 -> 勾选 **“启用开发者控制台”**。
> 2. **地图安装（`.bsp` / `.nav`）：** 直接放入 `cstrike/maps` 文件夹内。
> 3. **MOD 模组安装：** 强烈建议在 `cstrike` 目录下新建一个名为 `custom` 的文件夹，然后把下载的 MOD 文件夹整体放进 `custom` 中（利用 Steam 管道化加载机制，安全且极易清理）。
> 4. **游戏内进图：** 进入游戏后按下键盘左上角的 `~` 键打开控制台，输入 `map 地图名` 即可加载。
